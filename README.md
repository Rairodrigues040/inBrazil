# 🇧🇷 InBrazil — Rotas do Brasil

O **InBrazil** é um aplicativo Android nativo desenvolvido em Kotlin com Jetpack Compose, com o objetivo de apresentar as regiões brasileiras por meio de conteúdos turísticos, culturais e educativos.

Atualmente, o projeto contempla as regiões **Norte e Nordeste**, com conteúdos sobre os estados do Acre e do Ceará.

## 📱 Funcionalidades

### 🌿 Região Norte — Acre

- Informações gerais sobre o estado;
- Apresentação de pontos turísticos e atrações naturais;
- Conteúdos sobre cultura e folclore acreano;
- Informações sobre povos indígenas e artesanato;
- Consulta de temperatura por meio de API externa.

### 🌊 Região Nordeste — Ceará

- Informações gerais sobre o estado;
- Apresentação de pontos turísticos;
- Conteúdos sobre cultura e características regionais;
- Informações sobre a Universidade Federal do Ceará — Campus de Russas.

### 🧠 Quiz Interativo

- Perguntas sobre geografia, capitais e cultura brasileira;
- Quatro alternativas por questão;
- Cronômetro de 20 segundos;
- Validação das respostas;
- Feedback visual e explicações educativas;
- Contabilização de pontos, acertos e erros;
- Tela de resultado.

### 💬 Sistema de Comentários

- Cadastro de comentários;
- Identificação do usuário pelo nome;
- Seleção de fotografias;
- Listagem dos comentários;
- Edição e exclusão de registros;
- Armazenamento local utilizando Room Database.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Utilização |
|---|---|
| Kotlin | Linguagem de programação |
| Jetpack Compose | Construção das interfaces |
| Material 3 | Componentes visuais |
| Navigation Compose | Navegação entre telas |
| Room Database | Persistência local |
| ViewModel | Gerenciamento de estado |
| Kotlin Coroutines | Operações assíncronas |
| Flow | Observação dos dados |
| Retrofit | Consumo de APIs |
| Gson | Conversão de JSON |
| Open-Meteo | Dados meteorológicos |

## 🚀 Como executar o projeto

### Pré-requisitos

- Android Studio;
- JDK compatível com o projeto;
- Android SDK;
- Emulador ou dispositivo Android.

### 1. Clone o repositório

```bash
git clone https://github.com/Rairodrigues040/inBrazil.git
```

### 2. Abra o projeto

Abra a pasta clonada no Android Studio.

### 3. Sincronize o Gradle

Aguarde o Android Studio baixar as dependências e concluir a sincronização.

### 4. Execute o aplicativo

Selecione um dispositivo Android ou emulador e clique em **Run ▶**.
